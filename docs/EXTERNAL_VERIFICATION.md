# 尚需本人参与的外部核验

工程测试使用合成数据。没有本轮学校登录、真实预约、真实签到或 Cloudflare 部署证据。以下阻塞不通过 mock、开安全开关或重置数据库解决。

| 编号 | 需要什么 | 原因与本地做法 | 禁止粘贴/上传 |
| --- | --- | --- | --- |
| E1 | 本人正常登录，确认当前页面及接口代际 | 在官方系统正常查看“我的预约”；油猴主动开启只读诊断，预览脱敏 index/getstatus，记录页面显示的状态含义 | Cookie、Headers、HAR、账号、UID、原始个人响应 |
| E2 | 房间规则与时段证据 | 正常查看房间规则，核对提前天数、放号时间、时间步长、最短/最长时长、开放区间和规则有效期；提供非敏感规则文字或来源，不能沿用历史 22:30 猜测 | 带 enc 的完整页面 URL、私人页面源码 |
| E3 | 预约资格与座位冲突语义 | 只在正常业务中观察；维护者建立字段路径与界面含义矩阵，确认资格布尔值针对目标房间/座位有效，明确拒绝 code 是否证明原提交没有成功 | 私人响应、签名、验证码；不要为了取样制造冲突/监督 |
| E4 | 到馆真实签到和正式窗口 | 本人到馆按学校要求扫码/校园网/定位/人工操作，再正常查看预约。记录“已签到”与对应脱敏状态，核验校方窗口和是否允许无人值守 | 二维码、定位凭据、过期码、他人资料 |
| E5 | 发布许可及真实单次目标 | E1–E4 审核后，由维护者准备 secret 和发布方案；本人明确指定日期、房间、时段与座位再受控实测 | 不能把令牌或 Cookie 发到聊天/Issue/PR |

最少本人操作：正常登录查看规则与自己的预约；到馆按真实流程签到。维护者负责其余适配、映射、测试、Git 和后续发布，不需要用户编码或操作 SQL。

脱敏结构样本放本机 `worker/private-diagnostics/`，先人工预览；原始 Headers/HAR 不进入该目录。运行 `npm run check:contract -- private-diagnostics/sample.json private-diagnostics/profile.json` 仅验证解析，不构成本校生产许可。维护者为每个实际状态补充来源注释和回归测试后再讨论启用开关。

无法证实 unattended 签到时，能力保持 `NOT_AVAILABLE_UNDER_OFFICIAL_RULES`，产品使用“到馆操作 + 自动回读”。这表示当前证据不支持该能力，不是宣称已经取得校方禁止或允许的正式结论。

另有本地 GUI 验收阻塞 G1：computer-use 已发现 Edge，但浏览器控制授权超时，未完成真实 GUI 视觉/点击验收。本地离线控制页可用 `cd worker; npm run build; node scripts/preview-control.mjs` 复现；脚本不读取真实 secrets，全部学校请求拦截，使用公开合成令牌 LOCAL_PREVIEW_ONLY。没有伪造截图或将语法测试算作 GUI 通过。
